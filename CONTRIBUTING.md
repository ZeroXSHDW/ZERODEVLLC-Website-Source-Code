# Contributing — ZeroDevLLC.com

Keep the public landing page accurate, accessible, and free of secrets. Run
the documented `npm run quality` gate before review, preserve canonical-domain
and crawler controls, and never commit generated output or runtime values.

Use the exact Node.js version in `.node-version` (currently Node.js 22.23.1)
before installing dependencies or running the quality gate.

Describe the user-facing change, verification performed, deployment impact,
and any external blocker in the review handoff. Save or deploy only the exact
reviewed commit.
